# 🕌 Samarqand Choyxonasi — Milliy Taomlar va Restoran Ekotizimi

Zamonaviy veb-texnologiyalar (**HTML5, CSS3, Vanilla JavaScript**) asosida yaratilgan interaktiv o‘zbek milliy choyxonasi veb-ilovasi.

## ✨ Asosiy Imkoniyatlar
- **Vizual & Animatsiyalar:** Piyola bug‘i preloader, skroll progress-bar, 3D parallax, 4 fasl zarracha effektlari (Navro‘z, Yoz, Kuz, Qish), **Tun / Yorug‘ rejim** va **O‘Z / RU / EN** til almashtirgich.
- **Aqlli Menyu:** Milliy va yengil taomlar filtri, ovozli qidiruv, KBJU (kaloriya) kalkulyatori, portsiya hajmi (`0.7x / 1.0x / 1.5x`), taomlarni taqqoslash, Kombo-setlar va **Samovar choy konstruktori**.
- **To‘lov & Kuzatuv:** Promokodlar (`NAVRUZ20`, `CHOYXONA10`), hisobni do‘stlar bilan bo‘lish, choychaqa (tips), interaktiv masofa xaritasi, **3D aylanuvchi Uzcard/Humo/Visa karta**, **Click/Payme QR**, elektron chek va **Jonli kuryer kuzatuvi**.
- **Interaktiv Ekotizim:** Omad barabani, 360° virtual panorama, tapchan xaritasi va banket kalkulyatori, QR-ofitsiant chaqirish, AI-Choyxonachi chat-maslahatchi va Admin-panel.

